# Mobile Implementation Tasks

Unfinished mobile work only, in dependency order. Sources: `school/docs/MOBILE_TASKS.md` (old IDs in brackets), `WEB_UI_INVENTORY.md` (UI), `WEB_PAGE_INVENTORY.md` (measured values), the Mobile Parity plan (decisions D-1…D-12).

Rules for every task: web is the reference for behaviour, hierarchy, labels and states; native composition (sheets, segmented controls, sticky actions, Toasts); reuse the existing UI Kit, `useTheme()` tokens and `api/*` modules; React Navigation 7; all text via i18n (ar/fr/en, RTL); light/dark; phone and tablet. Tables become `DataCard`s with every column's information reachable. Backend authorization decides; hidden controls never replace it. No web defects are ported (placeholder demo data, silent validation, raw enums, `017.50` scores).

Already built, not repeated: navigation registry/tabs/More hub, auth and refresh, data/error layer, UI Kit, base dashboards, roll call, invoices list/detail/record payment, parent child views and fees, homework/resources lists, messages and notices (basic), registration review, i18n.

Not listed because the web has no page for them: syllabus, behaviour/merits, badges/leaderboard, forums, a separate file manager (the web "File Manager" is the homework assignments page, covered by the homework tasks). Release/EAS/store work stays out.
